# 산책핏 제품 범위와 업무 흐름

> 기준일: 2026-11-04  
> 제품군: `fit-survey`, `fit-admin`, `fit-app`

## 서비스 목적

산책핏은 실외 운동기구가 모여 있는 장소를 현장에서 조사하고, 사무실에서 사진과 설명을 정리한 뒤,
일반 사용자가 지도에서 지점과 설치 운동기구 정보를 확인하도록 제공하는 시스템이다.

운영자는 현재 한 명이다. 같은 관리자가 현장에서는 조사 PWA를, 사무실에서는 Windows 관리자 프로그램을
사용한다. 불특정 조사자나 일반 회원의 조사 등록은 현재 범위가 아니다.

## 전체 업무 흐름

| 단계 | 담당 제품 / 도구 | 작업 | 서버 전송 범위 |
| --- | --- | --- | --- |
| 1. 현장 조사 | `fit-survey` PWA | 운동기구가 모여 있는 지점의 위치·전경 사진·특이사항 등록 | 지점 위치, 전경 사진, 지점 정보만 전송 |
| 2. 기구 촬영 | 스마트폰 기본 카메라 | 지점에 설치된 각 운동기구 사진 촬영 | `fit-survey`나 산책핏 서버로 전송하지 않음 |
| 3. 사진 전달 | Google 포토 | 스마트폰의 운동기구 사진을 사무실 PC에서 확인 | 산책핏과 별도의 수동 전달 경로. Google 포토 API 연동 없음 |
| 4. 사무실 편집 | `fit-admin` Windows | 전경 확인, 기구 사진 편집, 기구 등록·설명 작성, 지점별 설치 기구 매칭 | 편집·검수한 공개용 지점/기구 정보와 이미지 저장 |
| 5. 공개 | `fit-admin` Windows | 지점과 설치 기구의 공개 상태 확정 | 공개 승인된 정보만 사용자 조회 대상 |
| 6. 사용자 조회 | `fit-app` PWA·토스 | 지도에서 지점 확인, 지점 상세와 설치 기구·기구 상세 조회 | 공개 데이터 읽기만 수행 |

## 제품별 책임

### fit-survey

- 관리자 한 명이 현장에서 사용하는 PWA다. 별도 네이티브 앱 출시는 현재 필요하지 않다.
- 지점 위치, 주소, 정확도, 전경 사진, 시설명과 특이사항을 등록하고 당일 조사 내역을 확인한다.
- 운동기구별 사진과 설명은 수집하지 않는다.
- 운동기구 사진은 스마트폰에만 저장하고 Google 포토를 통해 사무실로 전달한다.
- 위치·전경 사진·메모 전송 사실을 운영자가 알고 사용하는 내부 도구로 본다.

### fit-admin

- 같은 관리자가 사무실에서 사용하는 Tauri 기반 Windows 프로그램이다.
- 현장 지점 정보와 전경 사진을 검수해 공개 지점으로 승인한다.
- Google 포토에서 가져온 운동기구 사진을 로컬 이미지 도구로 편집·검수한다.
- 운동기구 카탈로그와 상세 설명을 등록하고 각 지점의 설치 기구·수량·표시 순서를 매칭한다.
- 지점·기구·사진·공개 상태와 필요한 데이터 정리를 관리한다.
- Google 포토 계정이나 API를 앱에 연결하지 않는다. 사진 선택·다운로드는 관리자 수동 작업이다.

### fit-app

- 일반 사용자가 별도 로그인 없이 공개 정보를 조회하는 지도 앱이다.
- 지도에서 공개 지점을 확인하고 지점 상세에서 설치 운동기구 목록을 조회한다.
- 운동기구 상세에서 명칭·모델·사진·운동 방법·효과·주의사항·설명 출처를 확인한다.
- 조사 원본, 미승인 지점, 관리자 기능과 편집 기능에는 접근하지 않는다.

## 권한 모델

| 주체 | 인증 | 허용 범위 |
| --- | --- | --- |
| 관리자 | Supabase Auth의 지정 계정 | 현장 조사 생성·조회·수정, 관리자 승인, 지점·기구·매칭·이미지 관리 |
| 일반 사용자 | 익명 | 공개 지점·공개 설치 기구·공개 기구 설명과 승인된 공개 이미지만 조회 |
| service role | 클라이언트 사용 금지 | 향후 서버 작업이 명확히 필요할 때만 최소 권한으로 별도 설계 |

관리자 여부는 로그인 여부 자체가 아니라 서버가 관리하는 allowlist로 확인한다. 현재 운영자가 한 명이더라도
모든 인증 사용자를 관리자로 인정하지 않는다. 향후 운영자를 추가할 때도 allowlist 등록 절차를 사용한다.

## 사진 경계

| 사진 | 생성 위치 | 산책핏 저장 | 공개 조건 |
| --- | --- | --- | --- |
| 지점 전경 원본 | `fit-survey` | 조사 단계에서 비공개 저장 | 관리자 승인·검수 후 공개용 경로만 사용자에게 제공 |
| 운동기구 원본 | 스마트폰 카메라 | 현장에서는 저장하지 않음 | Google 포토로 수동 전달 후 관리자 편집 |
| 운동기구 공개 이미지 | `fit-admin` | 편집·검수본 저장 | 기구 카탈로그 또는 지점 매칭 공개 상태에 따라 제공 |

조사 사진 버킷은 비공개가 기본이다. 일반 사용자에게 필요한 승인 이미지는 서명 URL 또는 별도의 공개 자산
계층으로 제공한다. Cloudflare R2 전환 시에도 조사 원본과 공개 파생 이미지를 분리한다.

## 현재 범위 밖

- 여러 조사자 계정과 조사자 조직 관리
- 일반 사용자의 로그인·즐겨찾기·제보·수정 요청
- 운동기구 사진의 `fit-survey` 업로드
- Google 포토 API·OAuth 연동과 자동 동기화
- 완전한 오프라인 지도·조사 동기화
- 관리자 외 사용자의 지점·기구·사진 변경
